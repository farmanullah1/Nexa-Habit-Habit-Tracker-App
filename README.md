# ✨ Nexa Habit – Premium Habit Tracker

![Nexa Habit Banner](https://raw.githubusercontent.com/farmanullah1/Nexa-Habit-Habit-Tracker-App/main/public/og-image.png)

> **Elevate your daily routine with the most refined habit tracker.** Nexa Habit combines iOS-inspired glassmorphism with high-performance analytics to help you master your consistency.

---

## 🚀 Experience the Future of Productivity
Nexa Habit isn't just a tracker; it's a premium experience designed for high-performers. Built with the latest technologies, it offers a seamless, calm, and focused environment to build lasting habits.

### 💎 Premium Features
- **🎨 Elite Glassmorphism UI**: Inspired by iOS 18+ design language, featuring soft gradients, backdrop blurs, and premium skin systems.
- **⚡ Heavy Animations**: Powered by Framer Motion and Lottie, experience silky-smooth 3D parallax effects, staggered transitions, and celebratory confetti.
- **📊 Advanced Analytics**: Visualize your progress with 30-day activity heatmaps and 7-day completion trend charts.
- **🏆 Gamified Achievements**: Earn and unlock premium badges as you hit new consistency milestones.
- **🌈 Dynamic Skin System**: Choose from 6 curated themes (Nature, Sunset, Ocean, Neon, etc.) to match your mood.
- **🔒 Private & Persistent**: All your data is stored locally using `localStorage`. No accounts, no tracking, total privacy.
- **🔊 Sensory Experience**: Custom-synthesized audio feedback for habit completion.

## 🛠️ Built With
- **Core**: [React 19](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (CSS-First engine)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) + [React Parallax Tilt](https://www.npmjs.com/package/react-parallax-tilt)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Utility**: [Date-fns](https://date-fns.org/), [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/farmanullah1/Nexa-Habit-Habit-Tracker-App.git
   cd Nexa-Habit-Habit-Tracker-App
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
